# 终端进度条优化 - 效果展示

## ✨ 新的整体进度条设计

### 设计特点

1. **单行整体进度条** - 不再为每个文件单独显示，而是在一行中展示整体进度
2. **实时统计信息** - 在进度条后显示 ✅下载数 ⏭️跳过数 ❌失败数
3. **当前操作提示** - 只在处理文件时显示文件名
4. **进度条更宽** - 从20字符增加到30字符，更清晰
5. **简洁明了** - 减少视觉干扰，专注于整体进度

## 📝 使用建议

```bash
# 推荐：安静模式 + 整体进度条
larksync sync-space --limit 50 --quiet

# 调试模式：显示所有日志
larksync sync-space --limit 50

# 全量同步：禁用增量策略
larksync sync-space --limit 0 --no-incremental --quiet
```

## 🎨 进度条格式说明

```
进度: ██████████████████████████████ 80% [8/10] | ✅3 ⏭️4 ❌1 | ✅ 当前文件.md
      ↑                            ↑    ↑       ↑           ↑
      30字符宽进度条                百分比  进度    统计      当前操作
```

- **进度条**: 30个字符，使用 █ 和 ░ 表示
- **百分比**: 当前完成度百分比
- **进度**: [已处理/总数]
- **统计**: ✅下载数 ⏭️跳过数 ❌失败数
- **当前操作**: 仅在处理文件时显示文件名（最多35字符）

## ✨ 优势

1. **清晰**: 一眼看到整体进度和统计信息
2. **简洁**: 不会被大量日志淹没
3. **实时**: 实时更新，无延迟
4. **美观**: 彩色输出，易于区分状态
5. **高效**: 减少终端滚动，提升体验
